
# 🍽️ Savory Haven - Restaurant Website

Savory Haven is a simple fictional restaurant website created to showcase a restaurant's menu, introduce the business, and allow visitors to try a reservation form.

This project was built as a beginner-friendly web development portfolio project.

## 🌐 About the Project

The website features a clean layout with a green and gold color theme. It is designed to be easy to navigate and simple to use.

## ✨ Features

- Responsive website layout
- Navigation menu
- Restaurant introduction section
- Food menu with sample dishes
- Reservation form demonstration
- Simple and attractive design
- Footer with copyright year

## 🛠️ Technologies Used

- **HTML5** – Structures the website content.
- **CSS3** – Handles the styling, layout, and responsiveness.
- **JavaScript** – Adds basic interactivity to the website.

## 📂 Project Structure

```text
savory-haven-restaurant/
├── index.html
└── README.md
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the restaurant website.

No additional software or installation is required.

## 📅 Reservation Form

The reservation form is for demonstration purposes only. It displays a confirmation message but does not save reservations or send them to a restaurant.

## 🎯 Project Purpose

This project was created to practise basic HTML, CSS, and JavaScript skills and to demonstrate my understanding of building a simple website.
